## 🚀 SnapBolt とは？

**SnapBolt（スナップボルト）** は、Windows 10 / 11 で毎日の手順書作成・バグ報告・開発業務を10倍速くするために設計された、**完全オフライン動作（外部送信ゼロ）・超軽量ネイティブ設計** のオールインワン画面キャプチャ＆録画ユーティリティです。

### ✨ 主な機能（v2.2 最新版）

1. **🎯 ウィンドウ＆UI要素の自動枠合わせ（オートスナップ）**
   - カーソルを乗せるだけで対象ウィンドウに青枠がピタッと自動吸着し、クリック1回で綺麗に切り抜けます。
   - **消えてしまうホバーメニュー・右クリックメニューも固定撮影**：`PrintScreen` キー、または上部バーの **「⏱️ 3秒後撮影」** でメニューを開いたまま丸ごと固定してキャプチャ可能です。

2. **✏️ 3秒で赤枠・モザイク・連番を入れて、そのまま `Ctrl + V` で即貼り付け**
   - 撮影直後に軽量エディタが0.1秒で起動。モザイク・赤枠・矢印・連番バッジ・蛍光ペンを入れたら **「📋 コピー & 完了」** を押すだけ！
   - いちいち名前を付けてファイル保存することなく、Word・Excel・Notion・Slack・Teams・GitHub Issue へそのまま `Ctrl + V` で貼り付けられます。

3. **🎬 MP4 / GIF 画面録画スタジオ（区間カット＆倍速編集つき）**
   - キャプチャ画面上部バーからワンタッチで録画モードへ切り替え。
   - 録画停止直後に **専用カット＆倍速スタジオ** が開き、前後の不要区間カット・2倍速化・字幕追加を行って、軽量なMP4または高画質GIFアニメーションとして即出力できます。

4. **📱 完全オフライン QRコード / バーコード読取 ＆ OCR文字認識**
   - 画面上の選択できないエラーメッセージや画像内の文字、PC画面に表示された **QRコード・バーコード** をドラッグで囲むだけで、100%オフラインで瞬時にテキスト・URL化します。
   - URLが検出された場合はワンクリックでブラウザで開けます。

5. **🎨 1pxルーペ拡大鏡つき 画面カラーピッカー（`#HEX` / `RGB` 色スポイト）**
   - キャプチャ中に `C` キーを押す（または上部バーの「🎨 色スポイト」を選ぶ）だけで、カーソル直下の1ピクセルのカラーコード（`#RRGGBB`）を即座にクリップボードへコピーします。

## 🌐 English Overview

**SnapBolt** is an ultra-fast, 100% offline-capable native Windows 10/11 screenshot, screen recording, QR/OCR, and color picker utility:
- **🎯 Auto Window & UI Element Snap + 3s Delayed Capture** for hover menus & tooltips (`PrintScreen`).
- **✏️ 3-Second Annotation & Instant `Ctrl+V` Paste** (Mosaic, Red Box, Arrows, Step Badges, Highlighter) without saving temporary files.
- **🎬 Built-in MP4 / GIF Screen Recording Studio** with timeline trim, 2x speed, and captions.
- **📱 100% Offline QR Code / Barcode & OCR Text Reader** (`Ctrl + Shift + O`).
- **🎨 1px Magnifier Screen Color Picker (`#HEX` / `RGB`)** (`C` key during capture).
